# Changelog

## 0.1.0

- Initial public release of this source on GitHub as `FelixJiashengFu/dsh-artifacts`, with the npm package name `dsh-artifacts-felix`.
- HTML, React, SVG, Mermaid, Markdown and code artifacts in a live side panel.
- Artifact version history, source view, downloads, session gallery, persistent storage and model calls.
- English and Chinese documentation, a screenshot, and CI for types, tests, build and packaging.
- Preserves the internal `dsh-artifacts` identity and session record format from the supplied 0.1.0 source.
